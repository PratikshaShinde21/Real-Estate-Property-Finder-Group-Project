# 🏠 NestFinder - Real Estate Property Finder

NestFinder is a React-based Real Estate Property Finder website
that helps users discover properties for buying and renting.

## 🌐 Live Demo
🔗 [nestfinder-realestate.netlify.app](https://nestfinder-realestate.netlify.app/)

## 🚀 Features

- 🏠 Home page
- 🔍 Property search
- 🏙️ Explore properties by cities
- ⭐ Featured properties
- ❤️ Wishlist
- 👤 Login and Register
- 💬 Talk to a Property Expert
- 📱 Responsive design
- 🌙 Dark / Light mode

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- React Leaflet
- Leaflet
- React Icons
- Vite
